# Design review checklist

기능 화면을 완료할 때 아래 항목을 코드 리뷰와 실기기 QA에서 확인합니다.

- [ ] `src/design-system`의 semantic token과 공통 컴포넌트를 사용했는가?
- [ ] 하드코딩된 색상·간격·font size가 없는가?
- [ ] 44px 최소 터치 영역을 지키는가?
- [ ] 긴 한국어·빈 데이터·오류·로딩·비활성 상태가 정의됐는가?
- [ ] 키보드가 입력 필드와 저장 버튼을 가리지 않는가?
- [ ] 스크린리더 label, role, state가 제공되는가?
- [ ] 색 이외의 방법으로 상태를 구분할 수 있는가?
- [ ] Android 시스템 뒤로가기가 데이터 손실을 만들지 않는가?
- [ ] 편집 화면의 취소·뒤로가기에서 미저장 변경 확인이 동작하는가?
- [ ] 삭제·결제·전송 등 위험 동작에 명시적 확인이 있는가?
- [ ] DEV 디자인 시스템 갤러리와 실제 Android 기기에서 시각 검수했는가?
